MySQL JDBC driver (Database member).

mysql-connector-j-8.4.0.jar is the driver that lets Java talk to MySQL (XAMPP).
It is already in this folder and on the Eclipse build path (.classpath), and it is committed to Git,
so everyone gets it when they pull. You don't need to download it yourself.

If Eclipse shows errors like "com.mysql cannot be resolved":
  right-click the project > Refresh (F5), then Project > Clean.
