Put the MySQL JDBC driver here (Database member).

1. Download "MySQL Connector/J" (Platform Independent) from https://dev.mysql.com/downloads/connector/j/
2. Copy the mysql-connector-j-x.x.x.jar file into this lib/ folder.
3. In Eclipse: right-click the jar > Build Path > Add to Build Path.
4. Commit and push BOTH the jar and the updated .classpath file, so everyone gets the driver.
